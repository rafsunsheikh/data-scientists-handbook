# Cybersecurity

> **Stub — contributions welcome.**

## Highlights to cover

- **Data shapes:** endpoint logs (EDR), network flows (NetFlow / IPFIX / Zeek), DNS, proxy / WAF, authentication (Kerberos, OAuth), email security, vulnerability scans, threat intel feeds, malware metadata.
- **Sources:** SIEM (Splunk, Sentinel, Elastic), EDR (CrowdStrike, SentinelOne), firewalls / IDS, identity providers, ticketing.
- **Cleaning particulars:** clock skew across hosts, log-format diversity (CEF, LEEF, JSON, syslog), IP-to-asset mapping, user-to-account mapping, alert deduplication, false-positive labeling.
- **Standard analyses:** anomaly detection (UEBA), threat hunting, alert triage / prioritization, incident clustering, MTTD / MTTR analytics, kill-chain attribution.
- **Visualizations:** event-rate dashboards, network graphs of host-to-host communication, attack-path graphs, MITRE ATT&CK heatmaps.
- **Regulation:** GDPR (log retention vs. minimization tension), HIPAA, PCI DSS, SOX, sector regulators (NERC CIP).
- **Public datasets:** CIC-IDS, UNSW-NB15, BoT-IoT, CTU-13, MITRE ATT&CK, MalwareBazaar.
- **References:** Sanders, Smith. *Applied Network Security Monitoring.* MITRE ATT&CK framework.
