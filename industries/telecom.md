# Telecommunications

> **Stub — contributions welcome.**

## Highlights to cover

- **Data shapes:** CDRs (call detail records), data session records, network performance KPIs, cell-tower events, churn, NPS, billing, customer support transcripts.
- **Sources:** network probes, OSS/BSS platforms, customer CRM, app analytics.
- **Cleaning particulars:** anonymizing CDRs, joining cell IDs to geolocation, deduplicating handover events.
- **Standard analyses:** churn prediction, network anomaly detection, propensity / next-best-offer, capacity planning, fraud (SIM-box, IRSF, subscription fraud).
- **Visualizations:** network heatmaps, customer cohort / churn curves, throughput dashboards.
- **Regulation:** GDPR, ePrivacy, sector regulators (FCC, Ofcom, BNetzA), data retention rules.
- **Public datasets:** IBM Telco Churn (Kaggle), Orange D4D challenge.
