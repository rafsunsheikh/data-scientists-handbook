# Retail and E-commerce

> **Stub — contributions welcome.**

## Highlights to cover

- **Data shapes:** orders, line items, sessions, page events, catalog (SKUs, attributes, images), inventory, returns, reviews, search logs, ad impressions.
- **Sources:** Shopify / Magento / commercetools, GA4, Segment, Amplitude, internal OMS/WMS/POS.
- **Cleaning particulars:** order vs. session vs. user identity stitching, return windows, currency / FX, taxes, bots in web events, attribution windows.
- **Standard analyses:** RFM segmentation, CLV / LTV, market-basket / association rules, demand forecasting, recommendation systems (collaborative, content, hybrid), price elasticity, A/B testing of UI.
- **Visualizations:** funnel charts, cohort retention heatmaps, geographic sales maps, recommendation explainability.
- **Regulation:** GDPR, CCPA, cookie consent (ePrivacy), age (COPPA).
- **Public datasets:** Online Retail (UCI), Instacart, Amazon Reviews, MovieLens (recsys), Rossmann Store Sales (Kaggle).
- **References:** Hastie/Tibshirani/Friedman. *ESL.* Aggarwal. *Recommender Systems.* Kohavi/Tang/Xu. *Trustworthy Online Controlled Experiments.*
