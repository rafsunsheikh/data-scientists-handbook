# Streaming Data Sources

> **Stub — contributions welcome.**

## What to cover

- Brokers: Kafka, Pulsar, Kinesis, Pub/Sub, Azure Event Hubs.
- Lightweight: MQTT, NATS, Redis Streams.
- Change Data Capture: Debezium, AWS DMS, materialize.
- Delivery semantics: at-most-once, at-least-once, exactly-once.
- Schema registries: Confluent Schema Registry, Avro/Protobuf evolution.
- Stream processing: Flink, Spark Structured Streaming, Kafka Streams, Faust, Bytewax.
- Windowing: tumbling, sliding, session.
- Watermarks and late data.
- Backpressure and consumer lag.
- Offline reprocessing from an archived stream.
- Connecting to analytical store: Materialize, RisingWave, ClickHouse Kafka engine.
